## 📁 Data Source & Methodology

The complete dataset is available in [`skills.json`](skills.json).

### Inclusion Criteria

- **AI Agent Skills**: Capabilities designed for AI agents (Claude, GPT, etc.)
- **Minimum Stars**: 100+ GitHub stars
- **Active Maintenance**: Repository updated within the last 6 months
- **Clear Documentation**: Has README with usage instructions

### Exclusions

- Human learning resources (tutorials, courses, workshops)
- Traditional skill development materials
- Non-AI agent projects
- Test projects or sandbox environments
- Web platforms (listed separately in Skills Web section)

### Categorization

Repositories are organized into **17 categories** based on their primary purpose and functionality.
